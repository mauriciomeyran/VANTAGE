# VANTAGE: SESSION OPEN LITE

1. Leer `agent.family` y `agent.instance` desde Project Instructions. No pedir confirmación.
2. Emitir:

```text
SESSION-OPENING...
```

3. Si existe un handoff entrante, leer su cabecera y validar `serial`, `generator`, `source_session`, `generated_at`, `schema_version` y `status`.
4. Emitir inmediatamente:

```text
HANDOFF RECEIVED
Serial: HO-000000
Generated by: AGENT_FAMILY/AGENT_INSTANCE
Source: SESSION-YYYYMMDD-X
Validation: ACCEPTED
```

5. Si falta un campo o existe contradicción, emitir `REVIEW_NEEDED` y no ejecutar escrituras derivadas.
6. Consultar la última fila del Session Ledger.
7. Crear o reanudar la sesión con:

```text
Session ID
Opened At
Status: OPEN
Pending Summary
Opening Handoff Serial
Opening Agent Family
Opening Agent Instance
Parent Session ID
Trace Status: LINKED | ORPHAN | REVIEW_NEEDED
```

8. Leer pendientes heredados.
9. Si no existe snapshot operativo, emitir:

```text
SNAPSHOT: 0 TAREAS CRÍTICAS
```

10. Terminar con:

```text
SESSION-OPENED: VANTAGE READY
```
