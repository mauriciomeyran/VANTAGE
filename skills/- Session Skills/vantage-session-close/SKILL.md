# VANTAGE: SESSION CLOSE LITE

1. Leer `agent.family` y `agent.instance` desde Project Instructions. No pedir confirmación.
2. Emitir:

```text
CLOSING SESSION — LITE...
```

3. Obtener el siguiente serial de `GLOBAL_VANTAGE_COUNTER` con formato `HO-######`.
4. Usar fecha y hora exactas de Ciudad de México.
5. Si falta identidad, declarar `IDENTITY_CONFIGURATION_REVIEW_NEEDED` y detener.
6. Si falta serial, declarar `HANDOFF_SERIAL_UNAVAILABLE` y detener.
7. Si hubo cambios documentales, registrar timestamp, serial y agente en Changelog cuando exista capacidad de escritura autorizada.
8. Si Census o sincronización requieren Terminal y no están disponibles, marcar `CENSUS PENDIENTE` o `SYNC PENDIENTE`. No afirmar `PASS` sin verificación.
9. Emitir:

```yaml
handoff:
  serial: HO-000000
  schema_version: "1.0"
  generated_at: "YYYY-MM-DD HH:MM:SS"
  timezone: America/Mexico_City
  generator:
    family: AGENT_FAMILY
    instance: AGENT_INSTANCE
  source_session:
    session_id: SESSION-YYYYMMDD-X
    ledger_status: OPEN
  parent_handoff:
    serial: null
  skill:
    loaded: true
    name: vantage-session-close
  status: DELIVERED
```

## S0 — Timestamp

`YYYY-MM-DD HH:MM:SS CDMX`

## S1 — Identidad e IDs

`HO-000000 | AGENT_FAMILY/AGENT_INSTANCE | SESSION-YYYYMMDD-X | Ledger: STATUS`

## S2 — Pendientes

Pendientes críticos y bloqueadores.

## S3 — Heredados

Deuda técnica heredada.

## S4 — Última acción

Estado verificado post-ejecución.

## S5 — Contexto

`VANTAGE: vX.Y.Z | Changelog: PASS/PENDIENTE | Census: PASS/PENDIENTE | Sync: PASS/PENDIENTE`

10. Actualizar Session Ledger cuando exista capacidad de escritura autorizada:

```text
Status: CLOSED-COMPRIMIDO
Closed At: YYYY-MM-DD HH:MM:SS CDMX
Pending Summary: S2-S5
Last Handoff Serial: HO-000000
```

11. Emitir exactamente:

```text
HANDOFF DELIVERED
Serial: HO-000000
Generated by: AGENT_FAMILY/AGENT_INSTANCE
Session: SESSION-YYYYMMDD-X
SESSION CLOSED — LITE
```
